Cara Publish Website ke GitHub Pages

Tutorial · Website

GitHub Pages memungkinkan website statis seperti IMVION dipublikasikan secara gratis, langsung dari repository GitHub. Berikut langkah dasarnya.

1. Siapkan repository

Buat repository baru di GitHub, lalu upload seluruh isi folder website (index.html, folder css/, js/, assets/, dll) ke repository tersebut.

2. Aktifkan GitHub Pages

  • Buka repository → tab Settings
  • Pilih menu Pages di sidebar kiri
  • Pada bagian Source, pilih branch main dan folder / (root)
  • Klik Save

3. Tunggu proses build

Setelah beberapa menit, GitHub akan menampilkan URL website, biasanya dengan format:

https://username.github.io/nama-repository/

4. Cek path relatif

Karena website berada di subfolder repository (bukan domain root), pastikan semua path pada file HTML/CSS/JS menggunakan path relatif seperti css/style.css, bukan path absolut seperti /css/style.css. IMVION sudah dibangun dengan path relatif sejak awal, jadi seharusnya langsung berfungsi.

5. Update kapan saja

Setiap kali file di repository diperbarui (misalnya mengganti js/config.js atau gambar di assets/images/), GitHub Pages akan otomatis membangun ulang website dalam beberapa menit.
