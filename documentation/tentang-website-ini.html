Struktur & Cara Edit Website IMVION

Website · Panduan

Website IMVION dibuat agar bisa diedit tanpa perlu menyentuh banyak kode. Hampir semua konten diatur dari dua file konfigurasi.

js/config.js

Berisi nama situs, tagline, logo, background, daftar sosial media, konten halaman About, dan seluruh daftar tools. Tambah/hapus tool cukup dengan menambah/menghapus satu baris object di array tools.

js/documentation.js

Berisi daftar dokumentasi yang tampil di halaman Dokumentasi. Menambah dokumentasi baru = duplikat documentation/example.html, lalu tambahkan satu entry baru di file ini.

assets/images/

Semua gambar (logo, background, thumbnail dokumentasi) disimpan di sini sebagai file lokal. Mengganti tampilan cukup mengganti file dengan nama yang sama, tanpa mengedit kode.

css/style.css

Seluruh warna diatur lewat CSS variable di bagian paling atas file (:root), sehingga mengganti tema cukup dilakukan dari satu tempat.

Detail lebih lengkap beserta contoh langkah-demi-langkah tersedia di file README.md pada bagian "CUSTOMIZATION".
