Mengenal Dasar Static Site

Teknologi · Dasar

Static site adalah website yang isinya berupa file HTML, CSS, dan JavaScript siap-pakai — tidak ada proses di server saat halaman diminta. Berbeda dengan website dinamis (PHP, Node.js, dsb) yang membangun halaman secara real-time dari database.

Kelebihan static site

  • Cepat — tidak ada proses render di server, file langsung dikirim ke browser
  • Aman — tanpa database atau backend berarti permukaan serangan jauh lebih kecil
  • Gratis di-hosting — layanan seperti GitHub Pages menyediakan hosting static site tanpa biaya
  • Mudah dirawat — cukup file teks, bisa diedit dan di-backup dengan mudah

Kapan cocok dipakai

Static site sangat cocok untuk website pribadi, portal dokumentasi, landing page, atau portofolio — seperti IMVION — di mana kontennya tidak butuh interaksi database yang kompleks.
